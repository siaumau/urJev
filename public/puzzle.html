怎麼比較才公平？

按下開始才同時送出第一個請求，起點、規則、步數與時間上限相同；之後盤面隨各自決策改變。每次只提供合法移動，不提供解答路徑，也不替模型搜尋下一步。

先完成正確盤面的一方獲勝。未完成就顯示未完成，不用歸位格數判勝。總時間包含 API 等待與畫面處理，單步延遲包含網路及回應解析；這是整個系統的解題能力與速度比較，不是純 GPU 速度比較。
