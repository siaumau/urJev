# 隱私說明

此外掛在使用者按下分析後，才會讀取已勾選郵件的主旨、寄件者、收件者標頭、日期、SPF／DKIM／DMARC 驗證標頭、摘要與本文，並透過 Gmail Profile 取得目前登入的 Gmail 地址來核對收件者。內容只會送往設定頁指定的 urJev 端點；預設是本機 `127.0.0.1:15413`。

為了讓 Chrome 側邊面板關閉後能還原畫面，已載入的郵件摘要、勾選狀態與分析結果會暫存在 `chrome.storage.session` 的記憶體中。郵件全文與 OAuth token 不會寫入此暫存；重新啟動 Chrome、重新載入／更新／停用外掛時，Chrome 會清除這份 session 資料。

使用者按「儲存並學習」後，外掛會在 `chrome.storage.local` 保存寄件地址、主旨比對特徵（可能包含文字片段）、驗證是否通過、原分類與修正分類。這些校正資料只留在本機，可從設定頁複製或清除；郵件本文不會寫入校正資料。

外掛不會：

- 儲存或匯出 Gmail OAuth token。
- 將郵件內容送到 Jev 官方 API。
- 刪除、移到垃圾桶或寄送郵件。
- 在背景持續掃描信箱。

只有使用者按下「執行分類」時，外掛才會建立或更新 `AI/*` 使用者標籤。若設定頁開啟「執行分類後移出 Inbox」，同一次操作也會移除 `INBOX` 標籤（封存）；郵件仍保留在 Gmail，並可從 `AI/*` 或「所有郵件」找到。
